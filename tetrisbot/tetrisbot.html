About

Autonomous Tetris-Playing Robot Manipulator

Fall 2025 • EECS 106A • UC Berkeley

TetrisBot is an integrated robotic system capable of perceiving, planning, and manipulating tetromino-shaped blocks to play physical Tetris autonomously. The system leverages computer vision for state estimation, Deep Reinforcement Learning for placement strategy, and motion planning for execution.

Design Criteria

Our system needed to reliably detect multiple objects in the workspace, compute space-efficient packing arrangements respecting stability constraints (>50% support), and execute collision-free trajectories to precisely place objects.

Key requirements included real-time perception, stable grasping, and efficient packing algorithms.

Design Choices
October 2025

ArUco Markers

Chose marker-based tracking over deep learning detection for reliability and precise 6-DoF pose estimation.

Internal Grasping

Designed custom hollow boxes allowing the gripper to grasp from inside, eliminating external offset errors.

Decoupled Planning

Separated packing order (learned via RL) from placement positions (height-map heuristic) for tractability.

Hardware Setup

Robot Arm

Universal Robots UR5e/UR7e 6-DOF collaborative robot arm with Robotiq parallel gripper.

Vision System

Intel RealSense D435i RGB-D camera mounted above the workspace for ArUco marker detection.

Custom Components

3D-Printed Cubes

Hollow cubes with ArUco markers on top surfaces. Internal handles enable consistent manipulation.

Software Stack

ROS Noetic on Ubuntu 20.04. MoveIt for motion planning, OpenCV for vision processing.

Perception System
Computer Vision Pipeline

ArUco Detection Node

Uses OpenCV's cv2.aruco module to detect markers through an RGB camera, organizes into different marker sizes based on ID, and calculates the 3D pose relative to the camera.

AR Tag Identification

Retrieves object information for each marker ID, computes centre offsets, transforms them to robot's base link frame, and publishes the organized data.

Custom Messages

BoxInfo.msg and BinInfo.msg store object dimensions, IDs, and base_link poses for downstream planning nodes.

Reinforcement Learning

RL Policy Network

Deep reinforcement learning planner (DQN/PPO) that learns optimal block placements from grid occupancy and piece geometry.

Reward Structure

Maximizes space utilization while minimizing height and holes. Balances line clears, height penalties, and stability bonuses.

Sim-to-Real Transfer

Policy trained in randomized physics simulation, transferred to hardware using domain randomization.

Motion Planning

MoveIt Integration

MoveIt handles IK trajectory planning with custom pose IK planner. Collision boxes in the planning scene ensure safe execution with velocity and acceleration constraints.

Grasp Planning

5-step pick-and-place sequence: 1) Pre-grasp, 2) Grasp, 3) Orientate, 4) Place, 5) Home.

Collision Avoidance

Dynamic collision objects prevent the arm from hitting previously placed boxes or workspace boundaries.
